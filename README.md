# Peak Form

Peak Form is a single-page gym website built with React, TypeScript, and Tailwind CSS. It introduces the club, lists training programs and membership plans, includes a BMI calculator, and shows how to reach the team.

## Sections

The home page is one scrolling page with these sections:

- **Hero** — rotating welcome slides with a call to join.
- **About** — a short introduction to Peak Form and the training space.
- **Offers** — weight-loss programs, bodybuilding programs, and special classes.
- **Membership** — day pass, 12-month, and monthly plans.
- **BMI calculator** — height and weight in centimeters and kilograms, with a result category.
- **Testimonials** — member feedback.
- **News** — short articles on yoga, trainers and equipment, and getting started.
- **Contact** — phone, email, and club address, plus a prompt to schedule a session.
- **Footer** — quick links and the same contact details.

- Node.js 18 or newer

## Setup

```bash
npm install
npm run dev
```

The dev server prints a local URL, usually `http://localhost:5173/`.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the Vite development server |
| `npm run build` | Type-checks the project and creates a production build |
| `npm run preview` | Serves the production build locally |
| `npm run lint` | Runs ESLint on TypeScript and TSX files |
